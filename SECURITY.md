# Security Policy

## Scope

This is a zero-dependency, single-file, client-only tool: everything runs in
your browser and the page makes **zero network requests after load**. There
is no server, no account system, and no data collection. The attack surface
is your own browser and this repository's static hosting (GitHub Pages).

## Reporting a vulnerability

If you believe you found a security issue, please open a private security
advisory at the repository's Security tab — please do not open a public
issue for vulnerabilities.
